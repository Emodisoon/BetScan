# Bet Scan

Java 25 + Spring Boot + Playwright. Первая версия: футбол, прематч, исходы 1/X/2
в основное время у BetBoom и PARI. REST API, периодическое обновление, диагностика.

**Сейчас это базовая версия для сбора диагностики.** Сайты недоступны из среды разработки.
Реальные DOM-селекторы ещё не настроены: первый запуск сохранит страницы и вернёт
`ERROR` с `NEEDS_CONFIGURATION`, если страница загрузилась. Пустой список не означает,
что у букмекера нет матчей. После получения HTML нужно настроить и проверить профили.

## Запуск

Нужны JDK 25 и Maven 3.9+. `java -version` и `mvn -version` должны показывать Java 25.
Все команды выполняются из корня проекта.

```powershell
mvn verify
mvn exec:java '-Dexec.mainClass=com.microsoft.playwright.CLI' '-Dexec.args=install chromium'
java -jar target/bet-scan-0.1.0-SNAPSHOT.jar
```

Вместо установки Chromium можно использовать установленный Chrome:

```powershell
$env:SCANNER_BROWSER_CHANNEL = 'chrome'
java -jar target/bet-scan-0.1.0-SNAPSHOT.jar
```

Приложение слушает `127.0.0.1:8080`. Первый автоматический обход — через 5 секунд,
следующие попытки — примерно каждые 5 минут. Параллельные обходы не запускаются.

## Что прислать после запуска

В другом окне PowerShell:

```powershell
./scripts/collect-diagnostics.ps1
```

Скрипт запускает обход (либо ждёт уже запущенный) и создаёт `diagnostics.zip`.
Пришлите этот архив: в нём HTML, скриншоты, сведения о DOM, статус API и лог.
Если сайт не загрузился, часть файлов может отсутствовать; причины будут в `report.json`.
Браузер работает в новом анонимном контексте, вход в аккаунт не нужен.

Linux/macOS: выполните `curl -X POST http://127.0.0.1:8080/api/scans`, дождитесь
`scanRunning: false` в `GET /api/matches`, сохраните ответ рядом с файлами `diagnostics/`
и упакуйте эту папку. Для Linux установка браузера: `install --with-deps chromium`.

## API

| Запрос | Результат |
|---|---|
| `GET /api/matches` | Снимки обоих источников, матчи, статусы и признак устаревания |
| `GET /api/matches?bookmaker=PARI` | Только PARI; также допустимо `BETBOOM` |
| `POST /api/scans` | Асинхронный обход; 202 принят, 409 обход уже выполняется |
| `GET /actuator/health` | Здоровье приложения, не доступность букмекеров |

Снимки хранятся в памяти и теряются при перезапуске. При ошибке старый снимок сохраняется,
но статус становится `ERROR`. Истёкшие матчи скрываются. Коэффициенты — `BigDecimal`;
времена в API — ISO 8601 UTC. `stale=true` означает отсутствие снимка либо возраст от 10 минут.
